# Local Pulse model worker scope

- authorized_scope: Weekday Pulse model inference moves to one outbound-polling Mac worker; GitHub retains collection, reservation, ledger, delivery and publication. Exact OAuth models: gpt-6-luna classification and gpt-6.1-sol synthesis. Fixed native prompts only, zero model tools, no paid fallback. Implementation and synthetic tests only.
- explicit_non_goals: No deployment, push, real generation, COS changes, scheduler/watchdog/vault ownership changes, Hermes changes, generalized runner, downloaded code execution, public ingress or credentials in GitHub.
- material_assumptions: Existing local gh login can read Actions and dispatch the single result workflow; an approved result workflow must be on main before activation. Public repository means request/result artifacts contain public news and existing public ledger only. Worker downtime fails boundedly, never buys API fallback.
- architecture_gate: Workflow/data contract change spanning GitHub producer and local executor; integrity and at-most-once inference require one run-bound protocol owner. Native pipeline owns synthesis validation; worker owns claim and transport. Existing consumers retain failure-status shape.
- acceptance_checks: Exact repository/workflow/run/attempt/hash checks; durable claim precedes model call; duplicates and unknown outcomes never auto-infer again; fixed file allowlist; full classification coverage and schema; existing synthesis validator; bounded poll/inference/result sizes; safe failure receipt; paid Radar unchanged; no tools, no fallback; fake GitHub round trip and integrated pytest.

Transport: Original workflow publishes one data-only request artifact and waits. Local worker reads that exact running main workflow, validates its identity, claims locally, invokes native classification/synthesis, and dispatches a fixed result-upload workflow with a bounded JSON envelope. The original workflow retrieves the exact result artifact from that workflow and validates all bindings before materializing only triaged.jsonl, brief.md and synthesis-dispositions.json. Inputs exceeding the GitHub workflow_dispatch payload limit fail safely; no alternative transport is silently selected.
